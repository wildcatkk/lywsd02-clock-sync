米家电子温湿度计Pro自动校时 · ESP32 版操作说明
==============================================

把这套固件烧进一块 ESP32-C3 开发板，板子就会自己连上家里的 WiFi，用蓝牙给附近的米家电子温湿度计Pro（LYWSD02MMC，也支持老款 LYWSD02）读数和校时。之后所有操作都在浏览器里完成，不需要电脑一直开着。


一、包里有什么
--------------

flash.bat           一键烧录并设置 WiFi
monitor.bat         查看板子的运行日志，也能输入调试命令
wifi.example.txt    WiFi 配置模板，复制成 wifi.txt 后烧录时就不用手动输入
firmware\           固件
    *-full.bin      完整镜像，flash.bat 用它，首次烧录或恢复出厂时用
    *-ota.bin       升级用固件，在网页上传，保留所有设置
tools\              脚本和 esptool.exe，不用动
logs\               monitor.bat 运行后自动生成，存放串口日志


二、首次使用
------------

1. 用能传数据的 USB 线把开发板插到 Windows 电脑上。
2. 想省事的话，把 wifi.example.txt 复制一份改名为 wifi.txt，填好 ssid= 和 password=。不填也行，脚本会在窗口里问你。
3. 双击 flash.bat。脚本会自动找串口、识别芯片、写入固件，然后通过同一根 USB 线把 WiFi 交给板子。
4. 连上后窗口里会显示网页地址，例如 http://192.168.1.50:8787/ ，用同一局域网里的手机或电脑打开即可。也可以用 http://主机名.local:8787/ 打开，主机名默认是 ESP32-C3-XXXX（XXXX 是板子 MAC 地址末 4 位）。
5. 用完可以删掉 wifi.txt，里面存着密码。

注意：
- 板子只支持 2.4 GHz WiFi，连不上 5 GHz。
- 完整镜像从 0 地址写起，会覆盖原来的设置，所以重新运行 flash.bat 等于恢复出厂。只想升级请用网页上传 -ota.bin（见第四节）。
- 提示找不到串口或识别不了芯片时：按住板子上的 BOOT 键，重新插上 USB，松开后再运行一次。

flash.bat 可以加参数（在本目录打开命令行运行）：
    flash.bat                 自动找串口，烧录并设置 WiFi
    flash.bat -Port COM5      指定串口
    flash.bat -NoFlash        不烧录，只给已经装好固件的板子设置或更换 WiFi
    flash.bat -NoWifi         只烧录，不设置 WiFi（之后用手机热点配网）


三、用手机配网（不用电脑）
--------------------------

板子在以下情况会打开一个没有密码的 WiFi 热点，名字就是它的主机名（如 ESP32-C3-XXXX）：
- 还没有设置过 WiFi；
- 已设置的 WiFi 连续 3 分钟连不上（期间它仍会继续重试）。

手机连上这个热点后，一般会自动弹出配网页；没弹出就在浏览器打开 http://192.168.4.1/ ，它会跳转到 8787 端口的配置页。选家里的 WiFi、输入密码，也可以顺便改主机名。连上后热点会在 1 分钟后自动关闭，手机切回家里的 WiFi，打开页面上给出的地址即可。


四、设备配置页 /config
---------------------

地址是 http://板子IP:8787/config ，主页面设置里的「设备」一栏也有入口。这一页是 ESP32 版独有的：

- WiFi：查看当前连接和信号，点「更换 WiFi」可以扫描并换一个网络，或者修改主机名。
- 时区：自动校时按这个时区计算。第一次打开主页面时会自动选成浏览器所在的时区，一般不用改。
- 固件版本：显示当前版本和芯片。点「上传新固件」选 firmware\ 里对应芯片的 -ota.bin，上传后板子自动重启，设置都会保留。新固件启动后如果连不上网络，会自动退回原来的版本。

配网阶段（连着板子热点时）这一页只显示 WiFi 设置。


五、主页面功能
--------------

主页面和 Windows、Linux 版完全一样：

- 扫描：找出附近的温湿度计。
- 读取：查看温度、湿度、电量和设备时间偏差，不会改动设备。
- 校时：把设备时钟改成正确时间。
- 自动校时：默认每周日 04:00 给所有开启「自动校时」的设备校一次，可以改成每天或关闭。
- 标签：点铅笔图标给每台设备起名字。
- 时间来源：默认用板子自己联网对好的时间；也可以在设置里选一个时间服务器（阿里云、腾讯云、国家授时中心等），每次读取和校时前先向它对时。服务器连不上时校时会跳过并记日志。
- 多节点：同一局域网里的多块板子、Windows 版和 Linux 版会自动互相发现，组成一个集群。每台温湿度计默认交给信号最强的节点负责，也可以在「所属节点」里指定；同一时间只有一个节点在用蓝牙，互不干扰。自动发现不到时，可以在设置的「手动指定的节点」里每行填一个，例如 192.168.1.51 。
- 节点按钮：点击页面上方的主机卡片，打开对应节点的页面。
- 运行日志：页面下方显示各节点的操作记录；只在页面打开时增量获取，不会随节点状态反复传输整段日志。

除时区、WiFi、固件外，其他设置都在主页面右上角的齿轮里，每个节点各自保存，互不同步。


六、查看日志和调试命令
----------------------

双击 monitor.bat 会重启板子并显示它打印的内容，同时保存到 logs\ 目录；按 Ctrl+C 退出。

    monitor.bat               自动找串口，重启板子后开始显示
    monitor.bat -Port COM5    指定串口
    monitor.bat -NoReset      不重启，直接接着看

窗口里可以直接输入命令，回车发送：

    info              固件版本、主机名、节点名、WiFi 状态和网页地址
    reboot            重启板子
    ntp [服务器]      测试时间服务器能不能连上，以及板子时钟偏差多少；不写服务器就用设置里选的那个
    selftest          运行内置的协议自检
    heap              显示剩余内存
    blecycle N        把蓝牙反复开关 N 次，检查内存是否稳定（默认 5 次）

提示：monitor.bat 占用串口时，flash.bat 无法使用，先关掉其中一个。


七、常见问题
------------

打不开网页
    确认手机或电脑和板子在同一个局域网；用 monitor.bat 输入 info 查看板子的 IP。部分路由器不支持 .local 地址，请直接用 IP。

板子一直开着热点
    说明 WiFi 连不上：密码不对、是 5 GHz 网络，或者离路由器太远。连上热点重新配网，或运行 flash.bat -NoFlash。

扫描不到温湿度计
    把板子放近一点（同一房间最稳），再点一次扫描。

Windows 或 Linux 节点发现不了板子
    电脑上的防火墙需要放行本程序（TCP 8787 端口和 UDP 8788 端口）。也可以在设置的「手动指定的节点」里填对方地址。

想恢复出厂
    重新运行 flash.bat，完整镜像会清掉所有设置和设备记录。
